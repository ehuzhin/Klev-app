# Klev

Калькулятор условий для рыбалки с автоматическим заполнением по геопозиции.

## Возможности

- Погода: температура воздуха, давление и его изменение за сутки, ветер, облачность и осадки.
- Местное время и сезон.
- Название места и ближайшие водоёмы на OpenStreetMap.
- Рыбы по наблюдениям GBIF в радиусе 10 км.
- Оценка условий и подсказки по выбранному виду рыбы.

Источники загружаются независимо. Отказ одного источника не прерывает заполнение остальных полей.
Температура воды вводится вручную. Оценка условий является упрощённой эвристикой, а не вероятностью улова.
Наблюдения рыб поблизости не подтверждают их наличие в конкретном водоёме.

## Технологии и данные

HTML, CSS и JavaScript без фронтенд-зависимостей. Серверная часть - Cloudflare Worker ESM.
Источники: Open-Meteo, OpenStreetMap / Overpass, Photon и GBIF. API-ключи не требуются.
Координаты передаются этим источникам после нажатия кнопки определения местоположения.

## Сборка

Нужны Node.js и Bash.

```sh
node scripts/embed-page.mjs
bash scripts/build-worker.sh
node scripts/validate-worker.mjs
```

Результат: `dist/server/index.js` и `dist/.openai/hosting.json`.
`worker/index.js` генерируется из `index.html` и `worker/runtime.js`.

## Структура

- `index.html` - интерфейс, автозаполнение и расчёт.
- `worker/runtime.js` - серверные API и отдача страницы.
- `scripts/` - сборка и проверка Worker.
- `.openai/hosting.json` - настройки существующего проекта Sites.
